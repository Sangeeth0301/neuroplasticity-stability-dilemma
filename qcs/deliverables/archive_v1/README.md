# `archive_v1/` — documents of the first version

These were produced before the readout of the circuit was changed from one qubit to all ten. They are correct for
the original system and are kept as the record of the build, but their headline results are superseded:

- they report the original circuit as significantly worse than the linear model (test MRR 0.919 against 0.975);
- the final circuit, which reads all ten qubits, ties the linear model (0.974 against 0.974).

Use the files one folder up (the Team_14 report and presentation) for the final results.
